All Pro Features Free & Unlocked
Paper size / PDF Mode
Specify how tall screenshots are formatted when exporting to PDF. "1 Continuous Long Page" saves the entire screenshot on a single seamless page without splitting.
Smart Page Splitting

Preserve Active Hyperlinks in PDF

🖼️ Image Capture & Formatting

Default Image Format
PNG is pixel-perfect and lossless. JPG applies 92% DCT compression for smaller file sizes.
Scroll Delay between slices
Paces scroll advancement to allow heavy single-page apps (Twitter, Notion, Linear, Apple Store) to populate lazy content.
Sticky & Repeating Elements Suppression
Detects fixed and sticky headers, banners, and floating bars and hides them after the first slice so they do not duplicate down the screenshot.
Recursive Shadow DOM Traversal
Recursively walks into web components and open shadow roots to locate sticky elements and complex media.
Fit Copies to Google Docs Limit
Automatically scales clipboard copy images down if they exceed Google Docs 25,000,000 pixel paste limit.
